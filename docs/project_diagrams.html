Held-out fit of predicting the old model's activation from the new one, averaged over 24 layers of Qwen2-0.5B to Qwen2.5-0.5B. 1.0 is a perfect translation.

Unconstrained maps beat the best rotation in all 24 layers, and the full map beats per-head maps in all 24 layers. The tiny transfer run uses 20-step adapters, so it checks the pipeline rather than proving the method.
